# GitHub Copilot Instructions

## General
- Use Python 3.
- Follow PEP8.
- Keep functions small and reusable.
- Avoid duplicate code.

## Flask
- Separate routes from Sudoku logic.
- Use helper functions where appropriate.

## Frontend
- Responsive design.
- Support dark mode.
- Use clean HTML/CSS.

## JavaScript
- Use modular functions.
- Avoid global variables.

## Testing
- Suggest tests before adding features.
- Do not break existing functionality.

## Documentation
- Explain major code changes before writing code.
